Successeur ML de IMGT/DomainGapAlign

Parcours ProtAnnotML

Six modules pour passer de l'immunogénétique IMGT à un modèle de langage protéique qui délimite les domaines, numérote selon IMGT, identifie gène, allèle et espèce, et annote FR et CDR. Chaque module mêle biologie, mathématiques avec exemples chiffrés, animations et code de référence.

Public doctorat / post-doc, bio-informatique et MLLangue du code anglaisMis à jour 20 octobre 2026

La chaîne d'entraînement visée

Point de départ

PLM de base

ESM-2, ESM C, ProtT5 ou un modèle anticorps (AbLang-2, AntiBERTy…). Choix à justifier par ablation.

Étape 1

DAPT

MLM sur un large corpus IG, TR, MH et IgSF, partitionné sans fuite.

Étape 2, optionnelle

TAPT

MLM sur les seules séquences des tâches cibles (train uniquement).

Étape 3

Fine-tuning MTL

Encodeur partagé, perte pondérée ou incertitude homoscédastique.

Sorties

Têtes

Région FR/CDR, position IMGT, type de domaine, segments V/D/J, gène, allèle, espèce.

Points ouverts relevés pendant la rédaction

  • Licence IMGT : la page des conditions d'utilisation indique CC BY-NC-ND 4.0, alors qu'un billet de l'OPIG (29 juillet 2026) annonce CC BY 4.0 depuis le 1er juillet 2026. À confirmer par écrit auprès d'IMGT avant toute redistribution de données dérivées ou de poids.
  • Règle des gaps de CDR1 et CDR2 : deux pages IMGT se contredisent ; la règle « sommet de boucle » est codée, à valider sur des sorties de DomainGapAlign (module 2).
  • Vérité terrain : des étiquettes issues de DomainGapAlign ne permettent pas de montrer qu'on fait mieux que lui ; prévoir un jeu de désaccords annoté indépendamment (module 6).
  • Concurrent direct : ANARCII (OPIG, 2025), numérotation par modèle seq2seq sans alignement, à inclure dans toutes les comparaisons.
